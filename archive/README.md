# Archive

This folder contains prototype or historical code removed from the production build path.

Archived items are kept for reference only. They should not be included from production headers or compiled by the default Makefile unless deliberately restored and revalidated.

Current archived groups:

- `analysis/validation_tests.*`: large historical validation harness.
- `dynamics/hierarchy_*`: recursive hierarchy prototype.
- `dynamics/pair_graph.*`: earlier graph/pair-count diagnostic helper.
- `dynamics/variational_*` and `variational_state.h`: tangent/variational prototype.
- `integrators/yoshida4.*`: experimental Yoshida wrapper.
- `integrators-helper/hernandez/state.*`: unused full HernandezState DTO.
